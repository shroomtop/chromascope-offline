Help (20s onboarding)
Fast start
  1. Go to Scan → tap Start.
  2. Drag/resize ROI onto the exact patch/LED you care about.
  3. Use Lock ROI so you don’t bump it.
  4. Tap Capture to add a color; or enable Auto-add.
  5. Go to Trigger → set Hue range + S/V mins → Arm.
Fix common failures
  • Hue drifts (AWB): narrow ROI, raise S min, capture White/Gray Ref.
  • LED flicker/PWM: lower Hz preset, increase hold/debounce; check Flicker hint.
  • Red wrap near 0°/360°: set min high and max low (wrap auto-handled).
  • Lag/jank: governor drops Hz; enable Safe mode.
  • No camera: permission denied or unsupported; use a compatible browser.
Privacy
Offline-only. No network calls. All data stays in this file + your device storage.
